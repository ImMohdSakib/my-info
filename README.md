# Mohd Sakib — Premium Full Stack Developer Portfolio

A highly animated, modern, professional and fully responsive personal portfolio website.

## Tech Stack

- React.js + Vite
- Tailwind CSS v4
- Framer Motion
- GSAP
- React Router
- Lucide React / React Icons

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## Features

- Dark premium futuristic aesthetic with glassmorphism
- Rich scroll animations and micro-interactions
- Sticky animated navbar
- Hero with rotating titles and floating tech badges
- Animated stats counters
- Interactive skills showcase
- Experience timeline
- Premium services cards
- Featured projects with live website previews (iframe)
- Separate projects page with filters
- Dynamic project details pages
- Contact form with validation
- Fully responsive (mobile-first)
- SEO optimized
- Scalable project data architecture (`src/data/projects.js`)

## Project Structure

```
src/
├── assets/images/     # Profile photo
├── components/        # All UI sections
├── pages/             # Home, Projects, ProjectDetails
├── data/              # projects.js, skills.js, experience.js
├── App.jsx
├── main.jsx
└── index.css
```

## Customization

- **Projects**: Edit `src/data/projects.js`
- **Skills**: Edit `src/data/skills.js`
- **Experience**: Edit `src/data/experience.js`
- **Resume**: Place `resume.pdf` in `public/` and update the About button
- **LinkedIn / Social**: Update Footer and Hero links
- **Education / Testimonials**: Placeholders ready for real data
